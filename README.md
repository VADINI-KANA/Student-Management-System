# Student Management System

## Description

A simple Student Management System built with Python and SQLite.

This application allows users to:

- Add a student
- View all students
- Search for a student by email
- Update a student's course
- Delete a student

## Technologies Used

- Python 3
- SQLite

## Project Structure

```
Student-Management-System/

├── main.py

```

## Features

- Create students
- Read student information
- Update student records
- Delete students
- Input validation
- Error handling
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository

```bash
git clone https://github.com/VALDINI-KANA/Student-Management-System.git
```

2. Open the project folder

```bash
cd Student-Management-System
```

3. Run the application

```bash
python main.py
```
